# Learning Games
A collection of links to game that help people learn the tools we use in the neue fische data analytics course


# List of games

|Topic|Game Name|Link|Comments|
|---|---|---|---|
|Terminal|Terminus|[Web Version](http://web.mit.edu/mprat/Public/web/Terminus/Web/main.html)|Browser based simulation of terminal interface.|
|Terminal|BashCrawl|[Gitlab Repo](https://gitlab.com/slackermedia/bashcrawl)|Uses your real terminal and file structure to explore the game. Recommendation is to git clone the gitlab repo. ```git clone https://gitlab.com/slackermedia/bashcrawl.git```|
|VIM Text Editor|VIM Adventures|[Web Version](https://vim-adventures.com/)|Browser based Zelda like game for learning naviagation in VIM|
|GIT|Oh My Git|[Website](https://ohmygit.org/)|Game to download and play to help learn git concepts|
|SQL|SQLPD|[Web Version](https://sqlpd.com/)|Browser based game for practicing SQL commands. Trial version is free to play|
|SQL|SQL-Island|[Website](https://sql-island.informatik.uni-kl.de/)|Browser based game for practicing SQL commands. Free to play. German and English possible.|
|SQL|SQL Murder Mystery |[Web Version](https://mystery.knightlab.com/)||
|API|SpaceTraders|[Website](https://spacetraders.io/)|Target audience is more app developers but python can be used to interact with game API in programatic way|
|Data Engineering|Big Data Game!|[Web Version](https://www.firebolt.io/big-data-game)|Looks fun|
|Statistics|Statgames |[Application to download](https://economics-files.pomona.edu/GarySmith/software.html)|there is StatQuiz, which are multiple choise questions (statical data and statistical inference) and a StatGames (Describing data, Statistical Inference and Uncertainty)|
|Statistics|Statistic Tutor |[Website](https://karlsigfrid.github.io/statisticstutor/output/exercises/sample_variance.html)|people can calculate different statistics, multiple choise questions (descriptive statistics, normal distribution, probability)|
